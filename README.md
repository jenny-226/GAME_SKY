# GAME SKY — LANDMARK STUNT TOUR

하늘을 나는 테슬라로 세계 명소를 누비며 점프 · 드리프트 · 공중 회전을 펼치는 3D 스턴트 게임 (Three.js).

## 실행

빌드 없이 바로 실행됩니다. 이 폴더에서 정적 서버를 띄우고 브라우저로 여세요.

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

GitHub Pages 에 올려도 그대로 동작합니다.

## 스토리

테슬라 비밀 연구소의 하늘을 나는 로드스터, 코드명 **SKY** 영상이 유출됩니다.
시험 주행자로 뽑힌 당신은 비밀 테스트 트랙에서 차를 길들인 뒤,
세계 명소를 도는 **스카이 투어 스턴트 쇼**에 나섭니다. 도시마다 현지 호스트가 이야기를 들려줍니다.

### 단계별 진행

- **1단계 · 점프 입문**: 램프, 목표 착지 패드, 콘 장벽, 메가 램프
- **2단계 · 드리프트 & 콤보**: 드리프트 존(점수 x2), 주차 차량 슬라롬, 미니 터보
- **3단계 · 스카이 피날레**: 스카이 링 비행, 끊긴 다리 점프 갭, 랜드마크 앞 SHOWTIME 피날레
- 별 3개: 결승선 통과 / 단계 미션 (PERFECT 착지, 드리프트 점수, 링 통과, 공중 회전, 콤보, 체공 시간) / 목표 점수
- 이전 단계를 클리어하면 다음 단계가 열립니다.

### 점수

- 공중 체공 시간 + 배럴롤 / 앞 플립 (연속 회전일수록 보너스)
- 착지: **PERFECT**(x1.5 + 보너스) / NICE / 실패 시 WIPEOUT
- 초록 목표 패드 위 착지 = **BULLSEYE** 보너스 (W/S로 속도 조절)
- 링 · 드리프트 · 착지가 이어지면 **콤보 배수** 최대 x5

## 조작

출발 신호(GO!)가 나오면 **차가 스스로 앞으로 달립니다.** 가속 키는 없습니다.

### PC (마우스만으로 플레이)

| 입력 | 동작 |
| --- | --- |
| 마우스 커서 좌우 이동 | 커서가 있는 쪽으로 방향 전환 |
| 마우스 왼쪽 버튼 (또는 `SPACE`) | 점프 · 비행 (누르고 있기, 에너지 소모) |
| 마우스 오른쪽 버튼 (또는 `SHIFT`) | 드리프트 |
| `Q` / `E` / `R` (선택) | 공중 좌 / 우 배럴롤, 앞 플립 |
| `F` (선택) | 착지 자세 잡기 |
| `ESC` | 일시정지 |

### 모바일

- 화면을 손가락으로 누르고 움직이면 손가락 쪽으로 방향 전환
- 오른쪽 아래 버튼: `FLY` (점프 · 비행), `DRIFT`, `LAND`, `⟲` `⟳` `FLIP`
- 설정에서 **왼손잡이**를 고르면 버튼이 왼쪽으로 이동

## 자동차 (차고)

- 차는 **테슬라 신형 로드스터** 한 가지로 고정 (낮고 뾰족한 쐐기형 앞코, 날카로운 옆 캐릭터 라인, 브론즈 유리 지붕, 뒤쪽 풀폭 레드 라이트바, 블랙 디퓨저, 6스포크 휠)
- 차고에서는 **색상만** 바꿀 수 있습니다 (12색 + 커스텀)
- 비행 모드: 공중에서 바퀴가 수평으로 접히며 파란 추진기로 변신

## 배경

- 기본 무대는 **🌾 시골길 드라이브**: 구불구불한 2차선 시골 도로, 밭과 목초지 조각보, 생울타리,
  빨간 헛간과 사일로가 있는 농가, 건초 더미, 풀 뜯는 소, 나무 울타리, 전봇대와 전선,
  먼 산 위의 풍력 발전기, 뭉게구름
- 월드 투어에서 다른 도시·명소 무대도 계속 고를 수 있습니다

## 파일 구성 (모두 이 폴더 바로 아래)

- `index.html` · `style.css` — 화면과 UI
- `main.js` — 게임 흐름, 스턴트 물리, 입력, HUD
- `stunts.js` — 단계별 스턴트 코스 생성 (램프, 링, 갭, 드리프트 존 등)
- `worlds.js` — 월드 목록, 스토리, 단계 데이터, 도시 배경
- `worlds-classic.js` — 테스트 트랙 · LA · 그랑프리 · 구름 하이웨이 배경
- `props.js` — 랜드마크 3D 모델
- `scene-kit.js` — 하늘(오로라 포함), 조명, 지형 공용 도구
- `cars.js` — 차량 공통 (바퀴, 색상, 비행 변신) · 도로 위 다른 차들
- `roadster.js` — 플레이어 차: 테슬라 로드스터 차체
- `worlds-country.js` — 시골길 배경
- `track.js` — 트랙(도로, 고가, 갭) 생성
- `utils.js` — 노이즈, 텍스처 도구
